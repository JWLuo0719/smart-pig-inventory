## 3. 关键口径速查（避免各文档说法不一）

| 口径 | 结论 | 出处 |
|---|---|---|
| 最小单元 | **栏舍（猪圈）= `penId`**，场/栋只是汇总视图 | A1 |
| 头数的定位 | **慢变量**：一次可信盘点管一个批次，不需要实时精确 | A2 |
| 视觉与控制的关系 | **视觉不进安全回路**；盘点数只调设定值，不调安全阈值 | A2 / C8 |
| 控制闭环在哪 | **边缘（场内主机）**，云端只下发策略；断网自治 | A3 / A6 / ADR-1 |
| 删除证据 | 未引用可删；**已被盘点引用的只可作废**（留痕） | C1 / A4 |
| 业务值生效 | 必须人工确认（`review_required` 是责任边界） | A5 |
| 多日平均 | 只在**无存栏变动区间**聚合，稳健口径，保留每日原值 | C3 |
| 隔壁栏舍的猪 | 边界裁剪 + 越界过滤 + **待裁决池**，绝不静默计入 | C5 |
| 归属方式 | **扫码强绑定**为默认（进入栏舍采集会话后连拍即可）；手工选择是弱绑定且必须留痕 | M2 |
| 自动化边界 | 低风险可自动；**通风最小量、下料量长期人工确认** | A5 / C6 |
| **实现归属** | 端管交互、边缘管推理与策略、**Spring 管主数据与账本**、PLC 管安全；本仓库 = 推理 Provider（+ 可迁移的代管账本） | §2.1（待签字） |
| **安全兜底承载方** | 硬联锁与 `SafetyDefault` 在 **PLC/认证控制器**，不在通用主机 | §1.4 / 不变量 9b |
| **几何标定** | 栏舍边界按**机位 + 版本**管理（`PenBoundary`），机位漂移则旧标定失效 | M13 / §1.1 |
| **时间口径** | `businessDate` 由**服务端**按猪场时区判定；端侧时钟偏移超阈值打标 | M11 |
| **证据上传** | 预览图优先、原图延后补传（两级上传） | M12 / P2 |
| **签字粒度** | 分级：低风险批量确认，异常与高风险逐条确认 | A5 |
| **待裁决池** | 必须有实体、责任人、时限与升级（`AdjudicationItem`） | §1.2 / P4 |
