# 牧数智核 · 完整部署说明

本包内含整套产品的源码、模型制品与安卓演示安装包，可在任意有 Docker 的服务器/电脑上独立部署运行。

## 包内容

| 目录/文件 | 说明 |
|---|---|
| `smart-pig-inventory/` | 产品主系统：Spring 业务后端 + Flutter 移动端源码 + Python 推理服务 + Nginx 网关 + 管理后台 |
| `pig-farm-agent/` | 模型侧：DCR-SoftNMS-YOLOv13 模型制品（model.onnx）+ 科研推理桥接服务（research_runner）+ 检测器代码 |
| `牧数智核-局域网演示版.apk` | 安卓 App（注意：内置服务器地址指向作者电脑，独立部署需按下方"App 连接"重打包） |
| `部署说明.md` | 本文档 |

## 一、环境要求

- Docker + Docker Compose v2（Linux 服务器或装有 Docker Desktop 的电脑）
- Python 3.10+（运行模型推理桥接服务）
- 端口：8088（网关）、9000（MinIO 对象存储，可选对外）、9001（模型推理服务）
- 首次构建需联网拉取依赖（约 10-20 分钟）

## 二、部署步骤

### 1. 启动主系统

```bash
cd smart-pig-inventory
docker compose up -d --build
docker compose ps   # 等 8 个容器全部 healthy
```

首次启动会自动建库、初始化组织与管理员账号。

### 2. 启动模型推理桥接服务（在 pig-farm-agent 目录）

```bash
cd pig-farm-agent
pip install -r requirements-runner.txt

# Linux 服务器：
RUNNER_MINIO_USER=minioadmin RUNNER_MINIO_PASSWORD=change-minio-me RUNNER_PORT=9001 \
  python research_runner/app.py

# 验证就绪：
curl http://localhost:9001/health/ready
```

`docker-compose.yml` 已为推理服务配置 `host.docker.internal:host-gateway`，
Linux 上容器内即可访问宿主机的 9001 推理服务（Docker Desktop 天然支持）。

### 3. 验证

- 网关：`http://服务器IP:8088/api/v1/system/capabilities` 返回 JSON
- 推理就绪：`http://服务器IP:9001/health/ready` 返回 `"ready": true`

## 三、App 连接

- APK 内置地址为 `http://172.17.193.107:8088`（作者电脑），连作者的局域网可直接用；
- **独立部署**需重新打包 App，指向自己的服务器（需 Flutter 3.x）：

```bash
cd smart-pig-inventory/apps/mobile
flutter build apk --debug --dart-define=API_BASE_URL=http://服务器IP:8088
```

## 五、模型与治理口径

- 模型：DCR-SoftNMS-YOLOv13 v1（ONNX，CPU 可推理）
- 当前为**研究模式**：自动计数关闭，所有结果强制进入"人工复核"，这是产品治理设计而非缺陷；
  解锁自动计数需走发布门禁（金标准验证 + 授权），见 `smart-pig-inventory/.env` 的 MODEL_* 项
- 上传照片时可在"标注不计入本栏的区域"页面画排除区（排除隔壁栏舍、料槽等）

## 六、常见问题

- **容器起了但 App 连不上**：检查服务器防火墙放行 8088；
- **推理全部 PROVIDER_UNAVAILABLE**：9001 推理服务没启动，或容器访问不到宿主机 9001；
- **PROVIDER_CONTRACT_ERROR**：模型输出被产品安全校验拒绝（fail-closed 设计），该照片转人工复核，证据不丢；
- **数据库要清空重来**：`docker compose down -v` 后重新 up（会删除全部业务数据）。
