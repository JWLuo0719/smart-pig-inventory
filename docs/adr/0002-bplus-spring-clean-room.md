# ADR-0002：路线 B+ 与洁净实现

状态：Accepted  
日期：2026-08-18

## 背景

项目收到上一届 Flutter/Next.js/Spring Boot/MySQL/Python 系统源码。其业务覆盖较完整，但源码授权、软著范围和第三方许可证未形成明确书面结论；同时现有实现不满足离线 Outbox、幂等上传、持久推理队列和模型版本审计要求。团队对 Spring Boot/MySQL 更熟悉。

## 决定

- 采用 Flutter + Next.js + Spring Boot/MySQL + MinIO + Redis + Python 推理服务。
- 以当前 PRD、OpenAPI 和验收标准为实现依据，不以 `eg/` 源码为派生基线。
- `eg/` 只允许核对功能覆盖、页面层级和部署问题；禁止复制源文件、SQL、素材、文案和模型。
- 当前 Django 实现冻结为行为原型，待 Spring 主干通过等价测试后再决定归档时间。

## 后果

- 可利用团队技术熟悉度并避免重复探索业务流程。
- 短期需要重新实现后端合同，但长期可获得清晰权属、持久任务和可演进模型边界。
- 必须维护需求追踪和独立提交证据，防止无意复制遗留表达。
