# ADR-0003：科研阶段轻量身份与推理结果回调

状态：Accepted
日期：2026-08-20

## 背景

当前系统仅供科研组内部使用，需要优先降低部署成本和运维复杂度；后续可能接入金蝶账号。移动端必须支持弱网离线采集，推理任务则通过 Redis/Celery 异步执行，但 Redis 不能成为业务事实来源。

## 决定

### 身份

- P0 由 Spring 业务服务提供轻量账号登录、短期 JWT 和可撤销刷新令牌。
- 密码使用 Spring Security 支持的自适应哈希；数据库只保存密码哈希和刷新令牌哈希，不保存明文令牌。
- JWT 包含用户 subject，不把客户端提交的 organizationId 当作授权依据。
- 用户可拥有多个组织成员关系；第一阶段 App 只激活一个组织，后续增加组织切换。
- 激活组织必须来自有效成员关系。后续接入金蝶账号时替换身份认证适配器，不改变组织成员、角色和业务授权模型。
- 设备离线时允许恢复和新建本机草稿，但不能同步。最长离线时限先以 7 天可配置临时值实现，正式试点前复审。

### 推理结果

- Spring 通过事务 Outbox 幂等派发推理任务。
- Python Worker 完成后，使用独立服务身份向 Spring 的版本化内部接口幂等回传结果。
- Spring 验证任务、结果状态和模型身份，在业务事务中写入最终结果和审计状态。
- 相同任务的相同最终结果重复回调视为成功；不同最终结果返回冲突并进入人工处理。
- Redis/Celery 只负责传输和执行，Spring/MySQL 是任务状态和盘点结果的唯一业务事实来源。

## 安全边界

- 研究阶段的轻量身份不等于开发免鉴权 Profile；共享网络部署仍必须启用认证。
- 登录和刷新接口实施速率限制，日志不得记录密码、JWT 或刷新令牌。
- 推理回调身份与普通用户身份分离，只允许写入指定任务结果接口。
- 正式接入金蝶前需要确认其身份协议、账号映射、停用同步和许可证条件。

## 后果

- P0 不需要额外运行 Keycloak 等身份容器，降低科研组部署成本。
- Spring 需要实现账号、刷新令牌、签名密钥轮换和撤销逻辑，必须有安全测试。
- 多组织数据模型从第一阶段保留，组织切换 UI 可以后置。
- 推理任务具备可恢复、可审计的最终结果闭环。
