# ADR-0001：产品、模型与许可边界

## 决定

- `app-yolo` 是产品源代码；`Manifold-YOLOv13` 是独立研究源代码。
- App 仅通过 `CountingProvider` 取得标准化检测结果，并记录模型和适配器版本。
- 默认推理 Provider 为 `unavailable`，无已验证服务时必须人工复核。
- 主工程源码仅接受经批准的宽松许可直接依赖。AGPL/GPL 代码不得复制或链接进主干；MinIO 作为可替换的独立服务部署，正式分发前必须完成 AGPL 义务评估，也可换用兼容 S3 的商业/云对象存储。

## 后果

模型升级、Agent 编排和端侧导出可独立演进，不会破坏盘点、证据锁定和审计合同。
