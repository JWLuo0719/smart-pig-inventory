# 项目边界

## 产品负责

- 组织、栋舍、栏舍、人员和权限。
- 采集证据、离线队列、上传、去重、锁定和审计。
- 盘点任务、人工复核、日盘点和综合盘点。
- 模型注册、推理任务编排和结果版本追踪。
- 金蝶同步适配器、日志和人工回退。

## 推理服务负责

- 根据版本化请求读取媒体并返回标准检测合同。
- 输出模型、权重校验值、适配器版本、检测框、置信度、质量告警和耗时。
- 不直接写业务数据库，不决定媒体删除、日盘点确认或 ERP 覆盖。

## 研究仓库负责

- 训练、消融、权重导出、金标评估和 Agent 实验。
- 只有通过固定数据集回归和许可证复核的版本才能注册到产品环境。

## V1 明确不做

- 视频计数结果、跨图自动去重、端侧实时计数、自动经营决策。
- 死猪上报；其后续引入必须有独立 PRD、数据口径、权限和审计设计。
- 未获得文档的金蝶真实字段猜测。
- 通过感知哈希自动删除照片。
- 物理删除已经形成盘点证据的媒体。
- 默认引入 AGPL/GPL 运行时。
- 学长代码、UI 素材、模型和数据库的直接迁移。
