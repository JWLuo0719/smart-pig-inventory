## 1. 产品简介

智慧猪场场主是面向猪场现场作业的多模态智能体产品，第一阶段以栏舍级猪只盘点为主要业务。现场人员用手机按栏舍采集照片，联网后由服务器返回检测候选，复核人员核对原图后确认数量，管理端再生成日报和综合参考。视频目前用于证据保存、翻阅和人工复核，不自动返回计数。

产品把每一张照片当作可追溯证据保存。每条证据都关联猪场、栋舍、栏舍、业务日期、采集时间和处理状态。确认后的证据会锁定，后续修改必须走有权限的审计流程。

产品已提供只读盘点助手的接口、工具和界面，后续可扩展更多模态与业务。目前试用环境的自然语言问答模型尚未启用，工作台规则研判可以读取已有业务数据。问答启用后，助手在授权范围查询任务、历史和证据，帮助用户理解业务数据；它不能越权确认数量、删除照片或修改主数据。

## 2. 能解决什么问题

- 让每次采集都明确对应到具体栏舍。
- 在弱网或断网现场先保存原图，恢复网络后继续上传。
- 把 AI 检测框作为复核依据，避免把机器候选直接当成正式存栏。
- 按栏舍、日期查询照片和盘点记录。
- 对已确认证据进行锁定和审计，避免结果被无痕修改。
- 以栏舍日报和多日确认记录支持猪场管理。

## 3. 用户和职责

### 现场盘点员

负责选择栏舍、拍照或导入、保存证据、查看上传队列和检查候选。

### 复核员

负责查看原图和检测框，处理邻栏入镜、遮挡、重复框和漏检，填写人工数量并确认锁定。

### 猪场管理员

负责维护猪场、栋舍、栏舍和账号范围，查看报表，处理失败任务和必要的审计更正。

### 系统管理员

负责系统、模型、推理任务和平台审计配置，不替代业务人员确认猪只数量。

## 4. 功能地图

### Android App

底部四个入口：**工作台、盘点、证据、我的**。任务、报告、助手和上传队列在对应页面进入。

| 入口 | 用途 | 下一步 |
|---|---|---|
| 工作台 | 当前组织/栋舍、当天栏舍矩阵、人工已确认合计、确认覆盖和协同研判 | 选栏开始作业，或打开复核；报告和助手使用页面对应入口 |
| 盘点 | 新建采集，查看已保存和待上传 | 点击“选择栏舍并开始” |
| 证据 | “服务器证据”和“本机草稿”两个页签 | 选日期/栏舍查询，或恢复本机草稿 |
| 我的 | 账号与当前组织、主数据同步、本机存储、网络策略、队列诊断和版本 | 同步资料或查看上传问题 |
| 顶栏上传入口 | 当前组织上传队列 | 立即重试或查看服务器处理结果 |
| 工作台菜单 | 历史任务与更多能力 | 查询往日任务；规划能力以实际状态为准 |

四列栏位按真实编码排列，不代表现场南北方位或通道布局。正式合计只包含已确认栏舍；覆盖未满时是部分合计。

### Web 管理端

## 5. 第一次使用

开始前准备已开通的账号、可用栏舍、联网环境、相机/相册权限及足够存储空间。首次登录和主数据同步需要网络。

### 安装与更新

从管理员提供的签名安装包安装。更新试用版时直接覆盖安装，不卸载、不清除应用数据，以保留未上传证据。安装后在“我的”核对版本号。安装包下载成功不等于已完成手机验收。

### 5.1 登录

1. 安装试用包并打开 App。
2. 使用管理员提供的账号和口令登录；采集和复核按角色分别授权。
3. 确认当前猪场名称、栋舍和栏舍列表正确。
4. 首次使用建议联网完成主数据同步。

登录后的数据范围由账号和当前组织决定。不要使用其他猪场账号测试本组织数据。

### 5.2 选择栏舍

1. 在“工作台”选栏，或进入“盘点”点击“选择栏舍并开始”。
2. 选择栋舍。
3. 搜索或点击具体栏舍。
4. 确认页面显示的猪场、栋舍、栏舍编码和业务日期。当前新建采集使用设备当天日期，历史查询可以选日期。
5. 再进入现场采集。

照片归属栏舍比文件名更重要。拍摄前确认门牌或现场标识。

## 6. 现场拍照和导入

### 6.1 实时拍照

1. 进入具体栏舍。
2. 打开采集页，默认使用单图模式。
3. 如需左、中、右采集，在开始拍摄前展开“更多采集方式”并开启三图模式。
4. 检查照片是否拍全本栏，是否拍入邻栏，是否有明显遮挡或模糊。
5. 拍摄并保存到本机，完整后点击“保存到待上传”。确认显示“已保存到待上传”再离开。

“照片已保存为草稿”和“已加入上传队列”是两个步骤。只拍照但未点击“保存到待上传”的草稿，可以在“证据→本机草稿”恢复继续作业。

### 6.2 从相册导入

1. 先选择目标栏舍。
2. 在当前采集页从相册导入照片；视频需先开启视频证据模式。
3. 确认每个素材的栏舍归属和方向。
4. 保存到本机证据库。
5. 点击“保存到待上传”，联网后上传。已经用系统相机拍摄的照片，也需在 App 选定栏舍后逐项导入；当前没有批量待归属素材箱。

当前版本没有把文件名或拍摄顺序自动当作栏舍归属。导入错误时应联系有权限的管理员，不要把“删除后重传”当作默认纠错方法。

### 6.3 左、中、右照片

左、中、右照片属于一次采集组，用于补足遮挡和视野。

- 三张照片的候选数量不能直接相加。
- 同一头猪可能出现在多张照片中。
- 看到邻栏或边界猪时，应在复核中处理或补拍。
- 料槽遮挡时优先换角度，不能把料槽整块区域都排除。

三图必须完整保存左、中、右三个方向后再加入队列。采集中途取消不会把不完整采集组当成已提交。

### 6.4 视频证据

开始采集前展开“更多采集方式”，开启“视频证据模式”。当前支持 MP4，时长大于0且不超过2分钟，文件不超过30 MiB（页面标为30 MB）。保存、入队、上传和播放按证据流程执行。

视频目前不生成自动计数，需人工观看和确认；当前版本的视频真机专项验收尚未完成。

### 6.5 本栏范围与排除区

在图片草稿中打开范围标注，标出本栏有效范围以及确实属于邻栏的区域。保存后随本组证据提交。图像内检测点按范围规则处理，边界归属仍需要人工核验。

不要为了让数字符合预期而排除本栏猪只，也不要在手持角度变化后直接套用旧范围。视频证据不使用图片范围标注。

## 7. 弱网和断网操作

断网时：

1. 继续选择栏舍和拍照。
2. 点击保存，等待页面显示“本机已保存”或“待上传”。
3. 确认完整草稿已点击“保存到待上传”；暂时没有数量不代表保存失败。
4. 不要卸载 App、清除数据或删除本机证据。

恢复网络后：

1. 打开上传队列。
2. 查看待上传、重试或阻塞项目。
3. 等待文件上传和整组提交完成。系统会继续原采集包，已成功文件不会重复传输；不承诺在单个大文件中按字节断点恢复。
4. 上传成功后等待服务器检测。
5. 进入复核页面查看候选。

408、429 等临时网络响应会自动重试。永久性权限或数据错误需要根据页面提示处理。手机系统可能限制后台执行，不承诺关闭 App 后立即上传；网络好时可打开 App 并从队列检查进度。

## 8. 如何理解盘点结果

| 显示 | 含义 |
|---|---|
| 本机已保存 | 原图已在手机，服务器尚未接收 |
| 待上传 | 等待网络或重试上传 |
| 上传中 | 正在传输 |
| 检测中 | 服务器正在处理 |
| AI 候选 | 模型给出的检测框或候选数量 |
| 待人工确认 | 需要人员核对原图 |
| 已确认并锁定 | 人工数量已成为正式业务记录 |
| 未知 | 没有可用的确认或候选值 |
| 失败待重试 | 上传或检测失败，保留失败原因 |

“AI 候选”不等于“正式数量”。正式日报只读取人工确认值。未知不能当成 0；人工确认的 0 头是有效业务结果。

## 9. 盘点复核

1. 打开待复核栏舍。
2. 查看原图和检测框。
3. 检查本栏边界、邻栏入镜、料槽遮挡和重复框。
4. 必要时切换原图/标注图，放大查看。
5. 在“人工确认”中填写实际数量。
6. 候选为空或与人工值不一致时必须填写8～500个字符的依据，例如“邻栏入镜，核对原图后人工清点确认”。只填“漏检”等过短说明不能提交。
7. 点击“确认并锁定证据”。

刷新失败时，页面会保留上一次读取的结果，并禁止在状态不确定时确认。请先刷新成功再继续。

没有“确认”权限时请由复核员或管理员登录处理。AI检测完成本身不会锁定证据，当前锁定时点是人工确认；已确认同栏同日的数量要改动时，使用后台审计更正。

## 10. 证据库

在“证据库”中可以：

- 按业务日期查询。
- 按栏舍查询；选项展示所属栋舍编码。
- 查看照片缩略图。
- 打开原图和对应盘点会话。
- 查看本机作业状态及服务器证据的删除、锁定状态，通过“查看盘点”打开对应结果。
- 处理权限允许的未锁定错误证据。

同一组织内相同文件不能重复上传。相似照片不会自动删除，只会进入复核提示。

已确认并锁定的照片不能由普通用户删除。管理员覆盖处理必须填写原因，并在审计日志中留下记录。

**删除错图的后果**：服务器标记删除并保留审计，本机原图保留，该采集会话不能继续确认，需要重新采集。已删除文件仍保留去重指纹，同一原文件不能通过“删后再传”更换栏舍。数量更正和媒体覆盖删除是两项操作，覆盖删除照片不会自动更正确认数量。

## 11. 日报和综合盘点

### 日报

日报按栏舍显示：

- 栋舍和栏舍；
- 人工确认数量；
- 业务日期；
- 可打开的盘点会话和关联证据。

待上传、检测失败、待复核和缺失栏舍不会被填成 0。

### 综合盘点

选择日期范围和栏舍后，可以查看。日报取范围结束日当天；综合平均取整个区间内该栏舍已有的确认样本：

- 原始平均值；
- 按规则取整后的展示值；
- 参与平均的日期；
- 近期开启的确认趋势；
- AI 候选与人工确认的对照。

日期首尾最多相隔366天。区间内没有确认样本时显示“未知”，不显示为0。例如23日确认30头、24日缺失、25日确认26头，综合平均为28头，参与日期为23日和25日；25日日报仍为26头。

管理端可按权限导出 PDF 或 Excel，单次最多366天、10000条记录。手机端用于浏览和复核，不把导出按钮作为所有 App 版本都有的能力。

综合平均是参考信息。期间发生调栏、销售、死亡或其他猪群变化时，不应直接把平均值当作目标日存栏。

## 12. 管理端操作

### 12.1 维护主数据

当前管理端以已授权组织为范围。管理员可以编辑当前组织的编码、名称和状态，新增或维护栋舍、栏舍；当前没有自助新增组织，金蝶 ERP 真实同步也尚未接入。管理员进入“猪场、栋舍与栏舍”：

1. 核对当前组织。
2. 编辑组织编码、名称或状态，或新增、编辑栋舍。
3. 在栋舍下新增或编辑栏舍。
4. 填写编码、名称和变更原因。
5. 保存后确认层级关系和启用状态。

父级停用前必须先处理子级状态；已有栋舍或栏舍不能直接移动到另一个父级。停用栏舍不会删除历史证据。手机端可在“我的→主数据同步”刷新已授权资料。

### 12.2 审核失败任务

管理员进入“失败推理任务”：

1. 查看失败代码、失败原因和模型信息。
2. 确认原始证据仍然保留。
3. 填写重试原因。
4. 创建后继任务。
5. 原失败任务不被覆盖，后继任务和审计记录保持关联。

### 12.3 媒体库

管理员可以按栏舍和日期查找证据。列表优先加载缩略图，打开原图需要明确操作。媒体库只显示当前组织授权范围内的记录。

### 12.4 审计更正

已确认记录需要修改时：

1. 打开确认记录。
2. 查看原始证据和历史版本。
3. 选择“创建审计更正版本”。
4. 填写新数量和更正原因。
5. 提交后核对新版本。
6. 原版本和证据引用继续保留。

## 13. 盘点助手

当前版本的助手工具和页面已具备授权范围内的只读查询基础能力，但试用环境的自然语言问答尚未启用。启用配置后，用户仍需按当前身份重新选择查询范围，例如：

- “今天哪些栏还没有确认？”
- “03 栏这次盘点是什么状态？”
- “03 栏最近几天的已确认数量是多少？”

助手回答由结构化事实、解释和来源记录组成。工作台的规则研判与问答模型相互独立；助手不可用时，核心采集、上传、复核和报表功能仍可使用。

助手当前不能：

- 直接确认数量；
- 直接改数；
- 直接删除照片或视频；
- 查询其他猪场；
- 把 AI 候选变成正式数据；
- 替代管理员权限。

## 14. 常见问题

### 照片拍不全

保留当前照片，在同一栏舍补拍左、中、右视角。复核时不要直接相加三张候选。

### 料槽遮挡

换角度或补拍。不要把料槽后方全部设为排除区。

### 邻栏猪进入照片

检查本栏范围和邻栏边界。无法判断时补拍或交给复核员。

### 照片选错栏舍

先停止确认，联系管理员进行归属核对。已确认记录不能由普通用户直接改归属。

### 上传后没有数量

先看任务状态。如果是检测中，等待处理；如果是失败待重试，查看原因；如果是待人工确认，进入复核。断网时本来就不会显示服务器数量。

### 页面显示登录失败

先恢复网络并重新登录。若手机还有待上传证据，不要清除 App 数据或卸载。此前报告的“彻底清后台后断网登录失败”问题按当前试用记录仍属于未完成真机验收事项。

### 删除后重新上传仍提示重复

系统会保留原文件指纹和审计记录，删除后不能用同一文件绕过去重。联系管理员核对栏舍归属；不要通过裁剪或改名制造错误证据。

### 有候选但不能确认

检查当前账号是否有复核权限、会话是否仍为待复核、证据是否被删除，以及页面刷新是否成功。按页面给出的失败原因处理后再试；不要把候选数量直接填入正式数量。

### 部分覆盖的合计是否代表全场存栏

不代表。工作台和日报只合计已确认的栏舍；仍待上传、检测中、待复核或缺失的栏舍不补成0。覆盖完成后再把合计用于业务判断。

## 15. 当前版本边界

当前版本已支持：

- 栏舍级组织和任务；
- Android 拍照、导入、保存和上传；
- 单图服务器检测候选；
- 检测框和原图复核；
- 人工确认、锁定、日报和综合参考；
- 管理端主数据、媒体库、失败重试和审计；
- 只读盘点助手的工具和页面基础能力（自然语言问答尚未启用）。

当前版本尚未作为正式生产能力承诺：

- 金蝶 ERP 真实同步；
- 三图跨图自动去重；
- 视频自动计数；
- 端侧离线自动计数；
- 自动把 AI 候选写入正式报表；
- 完整批次盘点管理；
- 真实猪场总体准确率；
- 正式生产备份恢复和完整真机验收。

## 16. 现场使用原则

1. 先确认猪场、栋舍、栏舍，再拍照。
2. 先确认原图已经保存，再离开现场。
3. AI 结果只作为候选，正式数量必须人工确认。
4. 未知、失败和缺失不当作 0。
5. 发现邻栏、遮挡或重复框时补拍或复核。
6. 确认后不要直接删除或覆盖证据。
7. 遇到异常先保留本机证据，再联系管理员。
