# 验收标准

## P0 现场试用门禁

### AC-01 离线草稿

断网选择栏舍并拍摄左、中、右三图，关闭 App 后重启，栏舍、方向、图片、ROI 和待上传状态完整恢复；界面不显示盘点数量。

### AC-02 弱网续传

上传第一张后断流，恢复网络只上传剩余文件；三张均完成后 Manifest 和 Commit 成功，本地包变为 synced。

### AC-03 幂等

相同创建、Blob、Manifest 和 Commit 请求重复或并发执行，服务器返回同一上传包和推理任务，不产生重复媒体。

### AC-04 精确重复

同组织内相同 SHA-256 图片跨栏舍再次提交被阻断，并返回原媒体引用；不同组织不互相泄露重复信息。

### AC-05 近重复

感知相似图片被标记为疑似重复并进入复核，但不会被系统自动删除或覆盖。

### AC-06 推理降级

Provider 不可用时任务进入 review_required，显示明确原因，不返回模拟数量。重试保留原任务审计链。

### AC-07 ROI

固定金标中，检测框中心在 ROI 外的不计数；边界规则有自动测试并与推理合同一致。

### AC-08 三视图

左/中/右作为一个 CaptureSet；多视角 Provider 未启用时不做简单相加，必须人工确认。

### AC-09 确认与锁定

复核员确认数量后所有引用媒体锁定。普通用户删除返回 409；管理员填写原因后只能软删除并生成 AuditEvent。

### AC-10 综合盘点

只取已确认日盘点平均值，保留原始均值和参与日期，展示值按规则四舍五入。

### AC-11 组织隔离与 RBAC

不同组织用户无法读取、修改或通过重复提示推断对方数据；操作员、复核员、管理员权限符合 PRD。

### AC-12 安全配置

生产配置无默认口令、无明文密码日志、MinIO 桶私有、CORS 为明确白名单，许可证扫描无未批准 AGPL/GPL 运行时。

## 测试矩阵

| 层级 | 必测内容 |
|---|---|
| Flutter | DB 迁移、草稿恢复、哈希、Outbox 状态机、权限拒绝、存储不足、EXIF 旋转 |
| Spring | 组织隔离、幂等 Commit、重复图片、锁定删除、审计覆盖、平均算法、迁移 |
| 推理 | Provider 合同、无模型降级、超时、重试、模型版本记录、金标回归 |
| Web | 登录刷新、权限路由、媒体复核、人工改数、失败重试、键盘操作 |
| E2E | 断网三图、杀进程、弱网恢复、推理/复核、确认、删除冲突 |
| 设备 | 至少一台低端与一台主流 Android，模拟高延迟、低带宽、断流和重复点击 |

任何 P0 验收失败都不得以“现场手工绕过”替代修复。
