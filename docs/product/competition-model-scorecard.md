# 参赛模型与现场评价成绩卡

状态：模板，尚无本轮实测成绩。每个候选版本复制一份填写；空白或样本不足保持“待测”，不得填预估精度、节省比例或研究集成绩代替现场成绩。

| 身份 | 待填写的证据 |
|---|---|
| 产品 | 源码版本/工作树清单 SHA-256、APK versionCode 与 SHA-256、签名公开指纹 |
| 服务 | 镜像 digest、Flyway 版本、Provider/适配器版本、模型 key/version/checksum |
| 授权 | 场景与拍摄授权编号、使用范围、脱敏/保留期限；原图留在受保护介质 |

| 真值 | 两名标注者独立清点、分歧复核规则、最终真值、无法确定的排除项 |
| 重复性 | 固定样本清单哈希、评价脚本/配置、随机种子（适用时）、原始结果位置 |

分别填三组结果：研究集离线评测、授权现场单图候选、人工确认业务结果；报告各组样本量和局限，不混合汇总。三图/视频没有批准总数时记录“仅人工证据”，不计算自动计数成绩。

计数指标：逐图绝对误差 `|候选−真值|`，MAE 为有效候选样本的平均绝对误差；完全一致率为零误差样本数/有效候选样本数，同时公布全部请求数、候选缺失/失败数及覆盖率。空栏真值为 0 时仍计入 MAE，比例误差不除以零。若给出检测 Precision/Recall/mAP，另列标注标准、IoU 阈值和评测实现；框分数不称准确率。

业务指标：记录采集开始、入队、服务端提交、候选返回、人工确认时间，分别计算采集用时、端到端等待及人工复核用时；Provider latency 只作其中一个阶段。公布有效样本数后再计算 P50/P95。人工对照采用相同栏舍/作业范围，说明操作者经验、顺序和异常剔除原因；不能从少量演示外推节省工时。

记录失败类型、重试次数、错图/重复图阻断、真实零值、未知及用户修改理由。报告格式：实测值、分母、样本分层、评价日期、评价人、证据引用、适用范围和限制。模型批准独立记录，本表不自动批准模型或自动入账。
