# 非功能需求

所有指标均为验收目标，不代表当前已经实现。

## 可靠性与弱网

- App 强制退出或设备重启后，已物化草稿和 Outbox 记录恢复率 100%。
- 单个图片 Blob 重试不得创建重复媒体；Commit 并发 20 次只产生一个业务任务。
- 2G/高延迟模拟下支持逐文件续传；已成功文件不重复上传。
- 后端或推理 Worker 重启后，持久任务可恢复，不长期停留在 processing。
- 服务端时间统一 UTC 存储，界面按设备/组织时区展示。

## 性能目标

- 主流实机基线为 realme GT 7 Pro（Android 15）；低端实机候选为 REDMI Note 14 5G 6GB+128GB。前者验证高端相机/高刷屏和最新系统路径，后者验证 6GB 内存、UFS 2.2 和中低端 SoC 下的弱网采集。两者均需以实测数据为准，不得从参数推导性能结论。

- Android 冷启动 P95 小于 3 秒（主流机），低端机小于 5 秒。
- 本地栏舍搜索 2,000 条数据 P95 小于 200ms。
- 不含 Blob 传输和模型推理的 API P95 小于 500ms。
- 10MB 图片上传的额外内存峰值小于 40MB；客户端和服务端均避免整文件多份常驻内存。
- 管理端核心页面在 4G 网络 LCP 小于 2.5 秒。

## 安全与隐私

- TLS 传输；生产环境禁止默认口令、匿名对象桶和调试模式。
- 密码使用自适应哈希；日志禁止记录密码、令牌、MinIO/ERP 密钥和原图内容。
- 组织隔离必须在服务端执行，不能依赖前端隐藏。
- 管理覆盖、权限变更、模型重跑、ERP 覆盖全部审计。
- 对象访问使用短期签名 URL；原图默认私有。

## 可用性与无障碍

- 现场主按钮触控目标至少 48dp，关键采集按钮至少 56dp。
- 状态不能仅依赖颜色；同时使用图标和文本。
- 支持系统字体缩放到 130% 不截断核心操作。
- 键盘焦点可见，管理端支持 Tab 导航；尊重 `prefers-reduced-motion`。
- 错误信息说明发生了什么、数据是否安全以及下一步操作。

## 可维护性

- API、数据库迁移、推理合同和 Flutter 本地数据库均有版本号。
- 新业务规则必须有单元或集成测试；关键状态机分支覆盖率目标 80%。
- 单文件建议不超过 500 行，领域服务不超过 300 行；超出需拆分或在评审中说明。
- 默认分支必须通过格式化、静态检查、测试、构建、迁移检查和许可证清单。

## 可观测性

- 所有请求、上传包和推理任务具有相关 ID。
- 指标至少包括上传成功率、队列深度、推理耗时、复核率、失败重试次数和重复拦截数。
- 健康检查区分 liveness 与 readiness；模型未加载不得伪装成健康可计数。
