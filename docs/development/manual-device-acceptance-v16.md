# v16 真机手动验收指引

适用设备：Redmi K60，已覆盖安装同一发布证书的 `0.1.0+18`。当前局域网入口是 `https://pig-inventory.local:8443`。自动检查已验证服务、mDNS/HTTPS 证书链、应用进程、认证恢复、首页任务加载、上传包自动恢复、Flutter 42 项测试、Release 配置和 Debug 构建。

## 开始前

- 保持手机与电脑连接到同一可信 WLAN；不要卸载应用、清除数据、关闭 TLS 校验或重置无线调试。
- 只使用有现场数据授权的新图片或 MP4。不要复用已经上传过的图片，精确重复会被服务器阻止。
- 不要对标为“已确认”“已锁定”的任务或照片执行删除、重新采集或确认操作。确认后原图会锁定；更正必须走管理员审计流程。
- 研究候选数只用于人工复核，`MODEL_APPROVED=false`。没有独立人工真值时不要点击“确认并锁定证据”。

## 1. 首页与任务读取（只读）

1. 在底部点“首页”。
2. 确认出现“网络连接已验证”，并能看到“今日真实任务”。
3. 点击“任务”，下拉刷新一次；确认当前日期的卡片没有“任务状态未知”或 `0 / 0` 假零。
4. 保持页面停留约 10 秒后告知开发人员“步骤 1 完成”。无线 ADB 会读回 UI 与服务端请求，不需要截图。

预期：网络可用时显示真实任务；没有任务时只显示“所选日期没有启用栏舍任务”，不会编造数量。

## 2. 单图采集、上传与待复核（产生新证据）

1. 在“盘点”页点“选择栏舍并开始”。
2. 选择一个未确认、未锁定的已启用栏舍；不要操作已确认任务。
3. 选择“单图”，拍摄或导入一张此前未上传且已授权的图片；仅在画面包含相邻栏舍时设置 ROI。
4. 点“保存到待上传”，再到“我的”→“上传队列与诊断”。
5. 等待状态变为“上传已提交”或“等待人工复核”。如果“正在创建上传包”持续约 30 秒，不要点击重试或放弃，直接告知开发人员包编号和当前文字；v18 会在网络/握手暂时失败时自动清理租约、重新安排后台任务并显示“等待自动重试”。出现“上传已阻止”时也不要放弃草稿或重新拍摄，先告知开发人员读取原因。
6. 完成后告知开发人员“步骤 2 完成”和页面显示的状态；保留页面，不要删除本机草稿。

预期：原图先安全保存在本机，上传按创建包、原图、清单、提交顺序完成；中断后只续传未完成部分。候选数量只能进入待复核，不能自动写入确认报表。

## 3. 人工复核与确认（仅在有独立人工真值时）

1. 在“任务”中打开状态为“需要人工复核”的任务，查看原图、候选数量和提示。
2. 用独立人工清点得到真值；记录样本编号、候选数、人工数和耗时。
3. 只有人工数确认无误时才输入数量并点“确认并锁定证据”。
4. 告知开发人员“步骤 3 完成”及候选数、人工确认数；不要对同一任务重复确认。

预期：确认后状态变为“已确认并锁定”，原图不可通过手机删除，日报和综合统计只读取人工确认数。

## 4. 图库、视频、同步与报表

按下面顺序逐项执行，每完成一项都保留当前页面并告知开发人员读取结果。

1. 图库：点“图库”→“服务器照片”，按日期和栏舍筛选，点“翻阅原图”与“查看盘点”。仅对明确错误且未锁定的测试照片使用“删除错图”；锁定照片应提示需要管理员处理。
2. 视频：选择另一个未确认任务，使用 MP4，时长不超过 2 分钟且不超过 30 MB。上传后应作为人工复核证据，不生成自动计数。
3. 主数据：点“我的”→“主数据同步”，确认同步时间更新并能选择当前组织的已启用栏舍；不在手机端伪造猪场、栋舍或栏舍数据。
4. 报表：点“任务”→“日报与综合盘点”，确认仅显示人工已确认数；无已确认记录时显示空状态，不显示候选数或估算均值。

## 5. 可选恢复测试

只在上述流程完成后执行：上传中切换网络或让应用进入后台，再回到“上传队列与诊断”。预期是本机原图和包/幂等键保留，恢复网络后只继续未完成阶段。不要在确认后测试删除或重新上传锁定原图。

## 结果回读

每一步只需告知“步骤 N 完成”和页面状态/候选数/人工数。开发人员会通过无线 ADB、服务端日志和数据库只读查询核对，不需要提供图片、账号、令牌或截图。真实图片与标注保持在授权的受控位置，不进入 Git 或候选包。
