# 参赛候选验收与演示记录

本清单绑定 [开发追踪](../product/competition-development-plan.md)，所有未填写步骤均为待验。只读工具合成测试不是在线 Agent 运行；公网入口、评审账号和报名提交另行实施。

## 同版本固定

记录日期、执行者、源码提交及未提交文件 SHA-256 清单、APK 版本/哈希/公开签名指纹、API 地址/TLS 公开证书有效期、每个运行镜像 digest、Flyway 实际最新版本、模型 key/version/checksum/adapter 和各批准开关。核对运行服务来自本次源码，健康旧镜像不作本轮证据。不能记录密码、JWT、服务密钥或私有原图路径到 Git。

候选冻结前执行 Spring test/verify、Admin test/lint/typecheck/build、Flutter analyze/test/Debug、签名配置检查及签名构建；本轮业务 API 构建基础镜像变化另执行 Compose 配置与隔离运行。只记录实测退出码与语义结果；跳过、资源失败和未执行单列。

## 演示脚本

主线约 5 分钟：说明目标用户与盘点痛点（30 秒）→今日任务直接带入栏舍/日期（30 秒）→采集及排除邻栏（60 秒）→上传作业卡与可恢复阶段（30 秒）→单图候选、原图带框缩放与规则依据（60 秒）→人工确认/锁图/更正版本/确认报表（90 秒）。实际时长以录屏为准。

异常分支单独展示 Provider 不可用后的人工复核，以及断网草稿恢复；可使用明确标记的合成故障环境，不能伪装成真实模型结果。准备同版本录屏、受保护的测试账号与已授权证据；录屏展示的版本与现场版本不同时说明差异。

## 发布与赛事扩展

发布清单：签名 APK、版本/哈希清单、部署/迁移/模型身份、自动与真机验收、[模型成绩卡](../product/competition-model-scorecard.md)、已知限制、演示录屏和恢复说明。缺任何必须项则保持候选未冻结。

团队确认赛事全称/届次/赛道、本校与官网截止、平台模型和外部访问要求。后续只读 Agent 里程碑按 [扩展契约](assistant-tool-extension.md) 开展；验证三个真实交互、受限评审账号、外部及匿名访问后才能声称 AI 大赛在线交付完成。本轮不执行注册、缴费或作品提交。
