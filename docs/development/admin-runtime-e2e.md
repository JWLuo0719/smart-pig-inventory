# 管理端隔离运行时回归

此回归补齐管理端构建/单元测试之外的浏览器与真实 HTTP 证据，不替代人工、真机或生产部署验收。

## 执行

工作站需要 PowerShell 7、Docker Desktop、Node/npm/npx 和系统 Edge。仓库根目录执行：

```powershell
pwsh -NoProfile -File scripts/run-admin-runtime-e2e.ps1
```

默认重建并启动固定 `pig-inventory-p0-admin-runtime`，网关只绑定 `127.0.0.1:8093`。成功后关闭测试浏览器并执行该项目的 `down`，不删除卷；失败保留栈用于诊断。`-KeepStack` 可保留成功栈，`-SkipBuild` 仅用于确认镜像已包含当前源码后的重复验证。

不读取产品 `.env`、个人浏览器配置、研究权重或真实媒体。生成的测试专用身份、环境、截图、浏览器快照与摘要全部在忽略目录 `test-assets/generated/admin-runtime/`，不得部署或发布其测试口令。每轮只增加带独立 UUID 的合成栋舍、栏位和证据，不删除历史测试数据。不要改项目名、改端口或复用 P0 卷。

## 覆盖范围与判定

1. 通过真实上传 API 完成 create/blob/manifest/commit；用服务密钥鉴权的失败回调建立夹具，人工确认 API 建立 17 头 v1。派发器关闭、Provider unavailable、模型批准为 false；本测试不声称覆盖 Worker 执行。
2. 系统 Edge 新进程登录管理端；Access Token TTL 为 5 秒，但保留产品 JWT 时钟偏差校验。轮询真实接口直到旧令牌被服务端拒绝，再点击刷新，断言并发面板请求只触发一次 Refresh。
3. 从任务卡片打开原始证据并确认图片可解码、证据已锁定；通过页面原生提示框将数量更正为 19，观察 v2 和日报更新。
4. 用真实同源 HTTP 读回 v1/v2、相同媒体、confirmed-only 日报及唯一审计；同键/同标准化理由重放相同 v2，改变数量返回 409。
5. 从失败任务卡片创建重试，原尝试显示不可变后继；本组织 OPERATOR 和第二组织账号更正均返回 404。
6. 验证浏览器无未捕获页面异常、localStorage/sessionStorage 不持久化令牌、刷新页面需重新登录。
7. 三个可选面板分别注入 503、404、网络中断、无效 JSON、成功空数组，共 15 组浏览器侧合成响应。每组验证加载状态隐藏旧行、失败不冒充空列表/无权限、不影响兄弟面板和真实任务、恢复后刷新可读；近重复告警未知时显示“—”，只有成功空数组显示 0。此段故障由浏览器拦截制造，不声称后端真实宕机。
8. 重新登录真实 OPERATOR/REVIEWER 账号，验证组织角色对应的无权限提示、禁止请求已知无权限的面板、不泄漏上次管理员面板行；此前管理员的真实数据读回仍单独验证。

CLI 固定 `@playwright/cli@0.1.19`。原生提示框会使 CLI 提前返回空 JSON，因此脚本还必须读回最终的脱敏完成标记；退出码 0、截图或空 JSON 都不能独自视为通过。异步 HTTP 过期轮询显式检查状态，不能把 Promise 本身当作已满足条件。最终通过证据为本机 `summary.json` 中的 `status=passed`。

## 2026-09-12 功能收口回归

浏览器脚本增加管理员新增栋舍/栏舍、按日期历史确认记录与均值、图库按栏隔离和覆盖删除审计。保持测试数据卷，测试实体编码每轮唯一。覆盖删除按现有合同返回 200，普通删除返回 204；CLI 原生对话框可能提前让出执行，因此始终要求最终语义读回，不能把空 JSON 当作成功。

视频补充只在本固定项目运行：先执行主脚本 `-KeepStack`，用已安装 OpenCV 的 Python 执行 `python test-support/admin-runtime/generate-video.py`，再执行 `pwsh -NoProfile -File test-support/admin-runtime/video-evidence.ps1`。合成 MP4 无真实猪场信息；视频脚本经真实 API/MinIO/Celery/回调验证候选数为空、原文件哈希一致、人工确认锁定及普通删除 409。接口的公开 inferenceSource 规范化为 server，脚本从固定测试数据库核对内部 manual-video-evidence 来源。手机录制与播放仍需设备验收。

成功后只执行该测试项目的 `down` 清理容器与网络，保留卷。禁止把脚本改向 P0 或正式服务。
