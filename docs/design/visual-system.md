# 视觉系统：栏舍作业台

## 设计立场

面向在猪舍内站立操作、可能戴手套、光照不稳定且网络较差的盘点员。视觉不追求农业插画或科技霓虹，而使用“栏舍门牌、任务夹和状态轨道”的作业语汇。

借鉴学长 App 的蓝灰运营感和五入口信息架构，但颜色、尺寸、组件、文案和素材全部重新设计。

## 初版品牌资产

- 产品名：**智慧猪场场主**。
- 初版图形标志：`apps/mobile/assets/branding/smart-pig-farm-owner-logo-v1.png`，同时供管理端 `public/` 使用。
- 标志含义：猪舍屋顶、猪只轮廓与核验标记，强调“现场证据已确认”，而不是泛化的 AI 或农业插画。
- 此资产由本项目的图像生成流程原创生成，仅作为可替换的初版视觉资产；尚未完成商标近似检索或注册，禁止据此宣称已拥有注册商标。

## 标志性组件：栏舍门牌

栏舍信息不是普通卡片，而是一块带左侧状态轨和切角编号区的“门牌”：

```text
┌─ B02 / 08栏 ──────────┐
│ 今日  未开始            │
│ 最近确认 126 头         │
│ 2 个采集包待上传   →    │
└───────────────────────┘
```

状态轨编码真实流程：灰=未开始、黄=待上传、蓝=处理中、紫=需复核、青=已确认、红=失败。必须同时显示文字。

## 移动端布局

```text
┌ 今日作业 / 网络与队列状态 ┐
│ 最近栏舍门牌               │
│ 继续上次 / 选择栏舍         │
│ 今日任务轨道               │
├ 首页 任务 [盘点] 图库 我的 ┤
```

- 页面水平边距 20dp；卡片间距 12dp；触控目标不小于 48dp。
- 中心盘点入口突出但不悬浮遮挡内容。
- 采集页每次只强调一个决定：栏舍 -> 模式 -> 方向 -> ROI -> 保存。
- 弱网胶囊固定显示“离线 / 待上传 N / 上传中 / 已同步”。

## 管理端布局

左侧窄导航、顶部组织与环境栏、主区使用两栏作业台。首页首屏不是营销指标，而是“需要人处理的任务”：待复核、上传失败、模型不可用和 ERP 冲突。

动画只用于一次页面进入和状态变化，持续时间 160–260ms；减少动态模式下关闭位移动画。

## 文案规范

- 使用用户动作：“保存到待上传”“确认盘点”“要求重拍”。
- 失败说明数据状态：“上传中断，原图已保存在本机；网络恢复后可继续”。
- 禁止“提交成功”这类模糊话术，明确对象和后续：“采集包已提交，等待服务器计数”。
