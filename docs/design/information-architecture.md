# 页面与信息架构

## 移动端

```text
登录
└─ 作业壳
   ├─ 首页：今日概览、最近栏舍、异常、继续作业
   ├─ 任务：任务列表 -> 栋舍进度 -> 栏舍详情
   ├─ 盘点：选栏 -> 选模式 -> 拍摄/导入 -> ROI -> 草稿/上传
   ├─ 图库：栏舍/日期 -> 媒体详情 -> 结果/锁定/删除限制
   └─ 我的：身份、同步、存储、网络策略、诊断、退出

全局子页面：栏舍选择、上传队列、盘点结果、人工确认、同步日志。
```

## 管理端

```text
登录
└─ 现场态势
   ├─ 任务管理
   ├─ 媒体审核
   ├─ 组织与栏舍
   ├─ 盘点报表
   ├─ 模型与同步
   └─ 审计日志
```

## 路由原则

- URL 和页面标题表达用户对象，不暴露内部队列或表名。
- 筛选条件应进入 URL，允许刷新和分享管理端工作视图。
- 移动端流程可从草稿恢复；任何中间页不得以返回键丢弃已物化媒体。
