## 结论

团队训练的 `v3_aligned_baseline` 权重能够通过现有外部 Runner 和产品 HTTP 合同完成单图推理，且权重 SHA-256 与 Runner 声明一致。它适合作为后续 P1 单图 Provider 的候选，但不会改变当前 P0 先完成弱网、复核和证据锁定验收的顺序。

当前仍保持 `research-http-yolo`、`MODEL_RESEARCH_ENABLED=true`、`MODEL_APPROVED=false`。研究结果必须进入 `review_required`；推理结果中的 `count` 保持为空。产品可以把单图检测框数量显示为待人工确认的候选值，但左/中/右检测框不得汇总为候选总数。

2026-08-30 已完成真实纵向链路：外部 Runner 启动时校验权重 SHA-256，产品经私有 MinIO、Celery Worker 和回调保存 25 个检测框，会话显示 25 个待复核候选；相同 Commit 重放仍返回同一推理任务。数据库中的业务 `count_value` 保持为空，日报没有新增记录。

## 可复现的数据集计数回归

两个候选使用的本地数据集逐文件一致。划分为 337 张训练图、102 张验证图和 61 张测试图，三个划分之间没有 SHA-256 完全重复图像。

仓库现提供 `scripts/evaluate_yolo_counting.py` 和 `scripts/run-team-yolo-regression.ps1`。脚本只读外部数据集和权重，先校验权重 SHA-256，只在验证集选择阈值，再把所选阈值固定后对测试集评估一次；本机 JSON 结果写入被 Git 忽略的 `test-assets/generated/`。运行时不复制图片、标签或权重。

测试集性能仅代表当前 Windows CPU 研究运行时：冷启动首图 1,408 ms，稳态平均 56.0 ms，稳态 P50 54.5 ms，稳态 P95 64.1 ms；含冷启动吞吐约 12.80 图/秒。它不是边缘服务器或 Android 端性能承诺。

此前手工记录的团队候选测试 MAE 0.967、WAPE 3.45%、±2 内 96.7% 无法由当前固定脚本复现，现标记为历史一次性结果，不再作为准入依据。直接以 `conf=0.60` 重新推理仍得到上表结果，说明差异不是阈值重放造成。测试集单独扫描曾出现 0.50 的 MAE 略低，但测试集不得用于校准，因此继续采用验证集选出的 0.60。

|---|---:|---:|---:|---:|
| 历史对照 | 0.65 | 1.246 | 4.45% | 88.5% |

默认阈值 0.25 下，团队候选的测试 MAE 为 1.377、WAPE 为 4.92%，因此 0.25 不应继续作为该权重的计数阈值。`0.60` 只是当前研究集上的候选校准值，不是生产配置。

测试集 61 张图片的标注数量全部为 28 头，覆盖范围过窄。该结果不能证明模型对空栏、少量猪、不同栏舍、严重遮挡、运动模糊、不同光照或多视角重复目标的泛化能力。

真实链路抽检使用该外部研究测试集的一张 28 头图片，在固定阈值 0.60 下返回 25 个候选。它证明链路会保留真实误差并等待复核，而不是证明模型已达到业务准确率。

## 与产品开发顺序的关系

1. 先完成 P0：三视图禁止相加、推理降级、管理端/真机复核、证据锁定和弱网 E2E。
2. P0 验收不再被模型训练阻塞；Unavailable Provider 仍是有效降级路径。
3. P1 外部 Runner 与自动化已完成当前阶段加固：启动时计算权重 checksum、严格 readiness、模型版本和阈值记录、验证集校准/测试集一次性全量回归、完整 MinIO/Worker/Callback E2E，以及 Docker 级 Provider 超时、Runner 停止/重启/恢复和回调失败分类测试；产品还会拒绝模型身份不一致、非法框或未知媒体，并按 ROI 重新计数。
4. 取得许可结论和覆盖真实业务场景的授权金标集后，才能评审 `http-yolo` 与 `MODEL_APPROVED=true`。
5. 多视角去重仍属 P2；在验证过的跨图去重 Provider 出现前，三图只能人工确认。

## 剩余门禁

- 模型代码、权重、运行时和部署方式的书面许可结论。
- 经授权的业务金标，覆盖不同数量、空栏、遮挡、模糊、光照、栏舍和设备。
- 固化预处理、ROI、阈值、硬件、延迟、失败率、模型版本和回滚方式。
- 管理端已通过真实 Chromium 自动回归：显示原图、25 个候选框及置信度、模型版本/checksum、2672 ms 耗时与研究警告；任务卡和日报均未把候选当作确认数量。人工视觉/可访问性验收按要求后置。
- 负责人对自动计数开关的显式批准。
